Prepare or run validation-front fit replays for the frozen adjustment source model set. Every source model was already trained on the full user training split and evaluated on the held-out validation back half. `prepare` preserves the frozen validation spec and changes only `eval_split` to `adjustment_fit`, which identifies the reserved front 50% of the validation split. `run` reuses a matching prepared manifest when present and otherwise prepares it automatically, then verifies every member before reuse. A complete manifest is never trusted by status alone: `eval.json`, prediction artifacts, reuse provenance, and the frozen source-model hash must still match. Valid members return as cached without new inference; invalid or incomplete members are rebuilt through the runner with `--reuse-model-from`. Local checkpoints and fitted statsmodels results are loaded, while foundation models are re-instantiated for inference only; model training is forbidden and `model/reuse.json` records `training_performed: false`. Replays write under `.forecast/adjustments/fit-runs/runs/`, never append to `.forecast/history.jsonl`, and never access held-out validation back-half or test rows for rule fitting.
