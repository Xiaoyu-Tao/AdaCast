Manage accepted adjustment skill versions. Use `accept_candidate` only after validation `adjusted_eval.json` reports an accepted decision. An accepted result remains eligible when `application_summary.zero_trigger` is true; a dormant rule is not the same as a harmful rule. When accepting a candidate, the tool records all accepted validation results for that candidate across the frozen source model set, but only if each result has a passing leakage audit. Accepted skills are versioned under `.forecast/adjustments/skills/versions/` and copied to `.forecast/adjustments/skills/active/`. Use `lock_active` before entering Critic test adjustment.
