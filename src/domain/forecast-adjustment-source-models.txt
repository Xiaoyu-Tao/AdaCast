Freeze the final raw source model set used for adjustment fitting. This tool reads `.forecast/history.jsonl`, resolves each candidate to a forecast-phase validation run that uses the fixed validation-front evidence contract and has complete prediction plus reusable-model artifacts, selects the best successful non-discard run per model family by held-out validation MSE, writes `.forecast/adjustments/source-model-set.json`, and records the locked source set in `.forecast/STATE.md`. A source is eligible only when its validation metrics are bound to the current model artifact and all evaluator inputs. Local trained models require `model/checkpoint.pth`; ARIMA requires `model/arima-results.pkl`; the other built-in statsmodels models require `model/statistical-results.pkl`; foundation models reuse their pretrained model reference. If a history run id points at an incomplete alias, the tool scans complete runs for a semantically identical stored spec. The frozen member uses the complete run and records the original `history_run_id`. Use it only after the raw Forecaster experiment search has stabilized.
