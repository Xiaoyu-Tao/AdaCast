# 实现状态：0.3

Lite 拥有自己的 CLI、依赖根、Python 包、数值引擎、领域规则和角色提示词；无需原项目安装或运行。

| 模块 | 实现 |
| --- | --- |
| 接口 | validate / run / resume / status / export；固定配置取代实时交互 |
| 运行时 | 原生 fetch 工具调用循环、SQLite、预算、完整输入输出审计、语义上下文压缩、隔离子任务 |
| 数据和模型 | 训练拟合 float32 多变量尺度；原统计/神经/基础模型实现；复用拟合产物推理 |
| 选择 | 验证集选各族代表，原始测试 MSE 选最终模型 |
| 调整 | 原条件规则、证据诊断、专家先验镜像、验证接受、版本冻结和匹配模型测试应用 |
| 反思 | 原校准策略、结构化证据循环、不可变状态、泄漏检查、失败恢复 |
| 交付 | 模型/scaler、预测、比较报告、SVG、规则/上下文/LLM 审计及哈希清单 |
| 发布 | 编译可执行文件、Python wheel、独立环境安装器、安装产物 smoke test |

运行时第三方 TypeScript 依赖为 Zod 和 gray-matter。科学计算依赖由 Python 包声明和 uv 锁文件管理；torch 与 Chronos 按需安装。

本轮范围、已对齐内容和暂缓项见 [0.3 对齐记录](ALIGNMENT_0_3.md)。历史数值对照见 [行为对齐说明](BEHAVIOR_ALIGNMENT.md)。运行方法与发布验证命令见 [README](../README.md)。

回归测试使用本项目保存的参考夹具，不要求原版目录。Agent 测试使用本地模拟 Provider；实际 LLM 搜索质量和 Foundation GPU 推理需要相应服务、权重及硬件另行验证。
