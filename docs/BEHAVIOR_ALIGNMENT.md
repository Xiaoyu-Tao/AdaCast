# AdaCast Lite 0.2 行为对齐说明

> 本文保留 0.2 的数值对照记录；当前 0.3 的本轮范围与暂缓项见 [ALIGNMENT_0_3.md](ALIGNMENT_0_3.md)。

## 目标和独立边界

本次将业务语义与原版对齐，同时保留独立安装、命令执行、中断恢复和交付接口。原版代码仅作为本次开发时的参考与对照基准；所需实现已纳入 Lite 自身的命名空间。运行、构建、回归测试和发布产物均不导入原版，不调用原版命令，也不需要原版目录存在。

计算实现位于 `python/src/adacast_lite_ml/engine/`，业务规则位于 `src/domain/`，角色提示词位于 `src/agents/`。运行桥接由 Lite 的 CLI、SQLite、LLM Client 和 Python JSON 协议实现。框架会话、TUI 和实时人工确认由固定配置及独立执行上下文替代。

## 已对齐的行为

| 范围 | Lite 0.2 的行为 |
| --- | --- |
| 数据 | 保留所有数值输入列、顺序和目标列索引；先转 float32，再只用训练集拟合 StandardScaler；遵守 ratio/timestamp 边界、gap、stride 和验证前后半划分 |
| 神经模型 | 使用同一模型定义、初始化、DataLoader 打乱顺序、训练损失和优化流程；默认 seed=42、epochs=5、batch=32、lr=0.0001；恢复测试时加载原拟合权重 |
| 统计模型 | 使用原版 statsmodels 模型与优化设置；ARIMA 默认 order=(1,1,1)；从训练边界连续预测，按窗口位置截取，不再对每个窗口重新套用近期历史 |
| 基础模型 | 保留模型仓库、固定 revision、封装、精度、聚合和设备规则；不再用较小的替代模型 |
| 指标 | 原固定 evaluator 的 MSE/MAE/WAPE/MASE，训练拟合的标准化目标尺度；绑定预测、数组、尺度和模型哈希 |
| 选择 | 每个模型族按验证 MSE 冻结代表；复用各代表完成原始测试；最终按原始测试 MSE 选模型；调整和反思结果不参与原始模型排名 |
| 外部预测先验 | 原 CSV 验证、float32 先验矩阵、首个被替换目标确定的全局 stride 网格，及测试阶段独立网格锚点 |
| 调整 | 原条件规则、外生变量语义、验证前半诊断、独立专家先验镜像、验证接受/拒绝、Skill 版本冻结、模型与规则匹配、测试前应用决策 |
| 窗口 | 原验证前半校准、确定性检测、验证记录、隔离 evidence-gap/seeking/unified reasoning 协议、结构化输出、不可变状态归约、失败重试和续跑 |
| Agent 与上下文 | 保留 Planner/Forecaster/Critic/window 提示词，并增加命令模式接口说明；完整消息与工具结果持久化；使用原 compaction 提示词生成语义摘要，保留完整工具调用/结果组和原始审计 |
| 决策与预算 | 必须交互的选择改为冻结配置或配置授权的自动决策；默认实验预算 20，连续无提升 3，连续崩溃 3；IPC/timeout 与模型崩溃区分 |
| 交付 | 保留原始/调整/最终预测、模型及多变量尺度、族代表与原始测试比较、规则和反思审计、LLM 输入输出及清单哈希 |

该选择协议使用测试结果选取最终模型。因此报告明确记录测试分数参与选择，不能将它当作选择完成后的独立泛化估计。

## 实际数值对照

对照环境为 CPU、torch 2.9.1、numpy 2.3.5、pandas 2.3.2、scikit-learn 1.7.2、scipy 1.15.3、statsmodels 0.14.5，seed=42，torch threads=2。

共 7 组配置、14 次验证/测试比较；验证集每组 1,728 个点，测试集每组 3,456 个点。逐点预测一致；四项指标也一致。数据契约另覆盖 gap=7/stride=24 的窗口坐标与标准化值。

完整原始记录见 [指标 CSV](parity-results/aligned/metrics.csv) 和 [对照结果 JSON](parity-results/aligned/summary.json)。原始 `parity-results` 目录保留对齐前的差异记录；`aligned/` 是本次结果。记录中的临时目录及旧项目路径仅是审计来源，不是 Lite 的运行依赖。

独立回归夹具位于 `python/tests/fixtures/`，保存参考实现生成的合成多变量序列、四个模型的验证/测试预测与指标、反思校准策略。测试不读取旧源码，覆盖 gap=2、stride=6、多变量目标索引、复用、外部先验全局网格和策略阈值；无 torch 环境只运行统计模型部分。

## 集成检查

`tests/alignment.test.ts` 使用真实模型产物检查模型族来源冻结、验证前半复用、诊断、条件候选、验证接受、禁止丢弃已接受候选、Skill 冻结，以及仅对匹配模型应用测试调整。`tests/workflow.test.ts` 检查真实工具执行、原结构化窗口协议、隔离输入、中断续跑、无效提案不能交付和重试后恢复。

LLM 请求、响应与结构化结果均有审计。当前会话没有配置真实 LLM 凭据，Agent 集成使用本地模拟 Provider；这证明协议与状态流程，不证明同一模型会生成相同实验建议、规则或最终文本。Foundation 权重下载及 GPU 推理未在本次数值对照中执行。

## 有意保留的接口差异

- 配置文件替代任务编辑和人工确认，状态以 SQLite 为准；不存在旧会话/TUI 对接接口。
- 修复原窗口实现对带时区时间戳的匹配错误；时间点、顺序和窗口语义保持一致。
- Python JSON 传输把未定义分母产生的非有限指标记为 null，避免非标准 JSON；普通有限指标保持原计算。
- Naive/Mean/SeasonalNaive/Linear 是显式 Lite 扩展基线，不代表原版同名模型的等价声明。
- 0.1 的运行检查点因数值契约变化拒绝直接恢复；0.2 的运行、恢复和交付互相一致。
- 单次试验、固定重放的数值一致，不等于任意硬件、依赖版本、基础模型权重或随机 LLM 搜索下的所有结果必然完全相同。
