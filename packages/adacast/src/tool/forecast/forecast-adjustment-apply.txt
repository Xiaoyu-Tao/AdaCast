Apply a deterministic adjustment candidate or active skill to a raw prediction run. The Python executor first creates a blind input without actual/residual/metric fields, then writes locked adjusted values and a separate adjusted_predictions.csv. Raw run artifacts are never modified, and prediction rows with no effective rule change remain exactly equal to their raw values. `apply-results.json` records unique matched rows, changed rows, triggered rule count, and whether the candidate had zero triggers. For `split: "fit"`, raw predictions come from `.forecast/adjustments/fit-runs/runs/<fit_run_id>/`. For `split: "test"`, the tool requires a locked active skill, matching candidate_id, an exact accepted validation counterpart, and an independent `apply` decision for that same test run. Multiple eligible models in one Critic test collection may be applied and evaluated separately.
