Read evaluation results for a completed experiment run. Takes a `run_id` and reads the `eval.json` artifact produced by the Python evaluator. Returns a decision-oriented summary with status, metrics (MSE/MAE/WAPE/MASE), comparison versus the current best result, per-window error distribution highlights, and elapsed time. IPC failures such as JSON parse errors or invalid subprocess output are reported separately from model crashes. Use this after `generate_model` when you need a detailed comparison summary.
