Create validation-front residual diagnostics for a completed adjustment fit run. This tool is only for `split: "fit"` and reads inference-only predictions from the fixed front 50% of the validation split, where actual values are allowed as adjustment-fit evidence. It writes a structured summary under `.forecast/adjustments/diagnostics/fit/<fit_run_id>/diagnostics.json` with task context, a dataset feature ledger, observed condition domains, window, horizon, timestamp hour/month/minute-of-day, raw-prediction-range bias buckets, numeric exogenous feature buckets, text/calendar/event exogenous domains, shifted day-level exogenous domains for prior/next-day rules, composite bucket summaries, and evidence-backed `rule_hints` for deterministic candidate design. It also stores evidence candidates independently as `evidence-experience.json`, `evidence-context.json`, and `evidence-knowledge.json`, with hashes and explicit classification boundaries referenced by the aggregate diagnostics. Every hint references this canonical diagnostics JSON rather than raw predictions. Do not use this tool on held-out validation back-half or test residuals.
