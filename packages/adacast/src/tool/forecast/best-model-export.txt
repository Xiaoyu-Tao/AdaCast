Create `.forecast/best-model/` for the Critic-selected global test-best forecast run.

Use this after final test-set evaluation and visualization generation, before writing the final report. Provide the validation run used for model selection and the held-out test run selected as global test best. The tool requires test-run provenance proving that the selected validation model was reused with `training_performed: false` and the same source artifact SHA-256. Both validation and test metrics must also be cryptographically bound to their current model and prediction artifacts. It verifies and copies test predictions and metrics, then exports the actual fitted artifact from the validation run: the final neural checkpoint, fitted statsmodels result, or immutable foundation-model repository commit. Copied local artifacts are hashed again before the package is installed. Missing, changed, or mismatched artifacts return `status: "blocked"` and preserve any previous completed package.
